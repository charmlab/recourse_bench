**Scope of Reproducibility**

We aim to reproduce the CFRL claims from `reference/cfrl.pdf`:

1. We replace iterative per-instance counterfactual optimization with a generator that produces batches in one forward pass : [Quantitative] : [Sections 4.6 and 5]
2. We train a DDPG actor/critic generator in an autoencoder latent space to produce sparse, in-distribution counterfactuals : [Quantitative] : [Sections 4.1-4.4, Tables 2-4]
3. We operate in a model-agnostic black-box setting using prediction feedback rather than model gradients : [Qualitative] : [Methodology Sections 4.1-4.4]
4. We support target and feature conditioning, including immutable features and one-direction numerical constraints : [Quantitative] : [Figure 1, Section 4.3, Section 5]
5. We evaluate the method on tabular datasets and show extension to MNIST/CelebA images : [Quantitative] : [Section 5, Tables 1-6, Figure 4]

**Methodology**

We reproduce CFRL with `experiment/cfrl/test_cfrl_reproduce.py` in the RecourseBench PyTorch environment. The current script covers Adult with a random-forest black-box model, CFRL training for 100,000 steps, and batch size 128. The local framework includes `reference/cfrl.pdf`, an implementation, and an Adult configuration, but the project artifact list did not confirm exact original code/data availability.

**Results**

Claims 1-4 are partially reproduced for Adult + random forest. Accuracy and validity are close: accuracy is 0.86 versus reproduced 0.859665, relative delta 0.0004; validity is 0.9859 versus reproduced 0.988, relative delta 0.0021. Immutability is fully matched at 0.0 violation rate. Sparsity and distribution metrics drift: categorical L0 has relative delta 0.746, numerical L1 has relative delta 0.329, and target-conditional MMD deltas exceed 0.83. Claim 5 is not fully reproduced because Covertype, other tabular datasets, MNIST, and CelebA are not covered.
