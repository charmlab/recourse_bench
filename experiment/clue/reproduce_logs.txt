**Scope of Reproducibility**

We aim to reproduce the CLUE claims from `reference/clue.pdf`:

1. We generate counterfactual explanations by minimizing predictive uncertainty in latent space : [Quantitative] : [COMPAS uncertainty tables]
2. We reduce epistemic and aleatoric uncertainty relative to the original factual inputs : [Quantitative] : [Tables 1 and 2]
3. We extend the method to image-style examples : [Quantitative] : [Image experiments and figures]
4. We show that the explanations are useful to users : [Qualitative] : [User-study section]

**Methodology**

We reproduce the tabular CLUE artifact path with `experiment/clue/test_clue_reproduce.py` using stored BNN/VAE-style artifacts. Code/experiments and data are available, but the current benchmark run focuses on COMPAS tabular uncertainty metrics and does not cover image experiments or the user study.

**Results**

Claims 1 and 2 are partially reproduced. Epistemic uncertainty is very close: Table 1 reference 0.71 versus reproduced 0.7071, relative delta 0.004; Table 2 reference 0.707 versus reproduced 0.7071, relative delta 0.00015. Aleatoric uncertainty is weaker: Table 1 reference 0.18 versus reproduced 0.2203, relative delta 0.183; Table 2 reference 0.044 versus reproduced 0.0, relative delta 1.0. Claims 3 and 4 are not reproduced by the current script.
