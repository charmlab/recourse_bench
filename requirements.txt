# Full development / reproduction environment: pinned versions of every solver
# backend, so any of the 30 methods can run from a source checkout. Installing
# the published package instead keeps the solvers optional -- see the extras
# table in README.md.
#
# PyTorch is deliberately NOT pinned to a CUDA build here. Pick the build that
# matches your machine and install it FIRST, then install this file:
#
#   CPU (~500 MB):
#     pip install torch==2.10.0 torchvision==0.25.0 \
#       --index-url https://download.pytorch.org/whl/cpu
#
#   CUDA 12.6 (~4.5 GB):
#     pip install torch==2.10.0 torchvision==0.25.0 \
#       --index-url https://download.pytorch.org/whl/cu126
#
#   pip install -r requirements.txt
#
# See https://pytorch.org/get-started/locally/ for other platforms (ROCm, other
# CUDA versions). Use --index-url, not --extra-index-url: the latter leaves pip
# resolving across both PyPI and the PyTorch index with no guarantee which one a
# given package comes from.
#
# Skipping the first step is fine on macOS and Windows, where the default PyPI
# wheels are already CPU-only. On Linux the default PyPI wheel is the CUDA build
# and pulls ~3.1 GB of nvidia-* wheels with it.
